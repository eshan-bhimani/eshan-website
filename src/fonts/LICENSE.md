# Bundled fonts

All three families are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/),
which permits bundling and redistribution with this site.

The `.woff2` files here are the Latin-subset variable builds served by Google
Fonts (`unicode-range: U+0000-00FF`), self-hosted so the build does not depend
on a network fetch at compile time.

| File | Family | Axes | Source |
| --- | --- | --- | --- |
| `eb-garamond-latin.woff2` | EB Garamond | wght 400–500, upright | https://fonts.google.com/specimen/EB+Garamond |
| `eb-garamond-italic-latin.woff2` | EB Garamond | wght 400, italic | https://fonts.google.com/specimen/EB+Garamond |
| `instrument-sans-latin.woff2` | Instrument Sans | wght 400–600 | https://fonts.google.com/specimen/Instrument+Sans |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | wght 400–500 | https://fonts.google.com/specimen/JetBrains+Mono |
